# 路线图

本页是尚未交付工作的计划，不是能力声明。版本由验收结果决定，不承诺日历日期；负责人为对应包维护者，尚未指定个人的工作在认领前不进入发布承诺。

| 阶段 | 交付与负责人 | 验收条件 |
|---|---|---|
| 当前审查收口 | CLI/MCP 与文档维护者：工具文档、事务入口、宿主发布扩展、生成事实块、双语导航、第二客户端评测入口 | 完整 CI、tarball 消费者及确定性复合任务通过；真实模型成绩单独列明 |
| 下一预发布 | Core/Backend 维护者：1.0 公共面清单与契约审计 | 以生成的 UAM 操作、Backend 方法、公开 exports 为清单；每个变更标注兼容影响、替代 API 与迁移测试 |
| 1.0 候选前 | Functions/测试维护者：编辑器功能 × read/edit/save/publish 能力矩阵 | 从固定 fixture、正式模型/操作与测试清单生成双语表；每格有证据路径，未验证明确标记；不以 round-trip 代替语义验收 |
| 1.0 候选前 | 渲染/测试维护者：可重复视觉验证宿主 | 固定运行时、字体与 viewport；逐 controller page 截图，验证引用/字体/遮罩/布局；保留前后图及像素差异。现有结构验证不算视觉通过 |
| 每次候选发布 | 评测维护者：Codex + Claude Code 安装包评测 | 同一 tarball 摘要、任务集与独立工作目录；提交版本化结果、客户端/模型版本、失败轨迹与成本/耗时。未运行记为未验证；不把模型分数设为 PR 门禁 |
| 1.0 前持续 | 仓库维护者：贡献入口与第二维护者培养 | 文档翻译/独立回归用例为 good-first-issue 候选；新维护者完成一次审查和发布演练，再分配正式权限 |

1.0 稳定面以生成契约为准，内部路径不纳入承诺。1.0 后公开 API 废弃至少保留两个 minor 版本，并提供迁移说明；移除只在 major 发布。1.0 前必要破坏性变更集中在明确公告的预发布周期，在双语 Changelog 中说明，不引入长期临时兼容层。当前尚未宣布 1.0。

参见[贡献](./development.md#贡献入口)、[评测](./agent-evaluations.md)、[契约](./contracts.md)与[架构](../architecture-overview.md)。
