# @openfairygui/test-utils

Shared test helpers and fixtures for OpenFairyGUI packages.

## Install

```bash
npm install --save-dev @openfairygui/test-utils
```

## Exports

```ts
import { getFixtureProjectPath, listFixtureProjects } from '@openfairygui/test-utils';
```

This package intentionally includes fixture projects used by integration tests.
